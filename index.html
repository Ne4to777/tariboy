01 / Define

Image

A reusable definition of how an agent works.

An image packages plugins, Agent Skills, and an ordered prompt template. Build it from an original directory containing Tariboyfile.yaml, inspect exactly what the agent will receive, and reuse it across agents.

Register the official tariboy-store repository and build official/basic, or build one for a specific role. Export runnable images to other hosts; keep the original source for rebuilds. Harness, model, and effort belong to agent configuration.

Explore images →

02 / Configure

Agent

A named agent, with its own runtime and working directory.

Create an agent from an image, then choose where it runs and which harness it uses. Configure its model, effort, working directory, and environment independently of other agents.

Use Claude Code, Codex, or OpenCode installed on the selected host. Start locally or connect a remote Linux host through your existing SSH configuration.

Create your first agent → · Connect a host →

03 / Collaborate

Interactive

Work with the agent directly.

Open Console for a live session with the selected harness. Give instructions, follow the work as it happens, and return to the same session after switching away.

Interactive and Autopilot are independent: enable either or both. For an ordinary terminal session without image instructions, choose bare:latest, which keeps Autopilot off.

Open Console →

04 / Automate

Autopilot

Keep work moving between conversations.

Run bounded iterations on a timer or in response to durable messages. The host daemon manages the loop, so closing the desktop app does not stop it.

Inspect triggers, outcomes, usage, and cost in Activity. Set budgets and deadlines, pause new iterations, or kill current work when needed. Pausing Autopilot leaves the interactive session alone.

Configure Autopilot → · Understand the controls →

05 / Coordinate

Team

Independent agents. Shared work.

Group agents with a lead, shared channels, and individually configured roles. Each member keeps its own image, harness, model, and runtime settings.

Native Tasks helps you decompose work, delegate it, track progress, and keep questions and answers attached to the task. Transfer team configuration as compose YAML or a portable archive, and transfer runnable images separately.
